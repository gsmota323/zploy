Features

Tudo que você precisa para
ir do código ao ar

Configurado pra você. Sem YAML manual. Sem infra para manter.

D
Deploy com Git Clone

Cole o link do seu repositório público e nós cuidamos do resto. Clone, build e deploy automático.

C
Docker Automático

Detectamos a tecnologia (Node.js ou Python) e geramos o Dockerfile ideal sem você precisar escrever uma linha.

K
Kubernetes Integrado

Cada deploy cria automaticamente um Deployment, Service e Ingress no cluster Kubernetes configurado.

A
Autoscaling por CPU

Configure min/max réplicas e alvo de CPU. O HPA cuida de escalar o seu app conforme a demanda.

R
Rollback com 1 Clique

Deploy quebrou? Revertemos para a versão anterior imediatamente via kubectl rollout undo.

S
Variáveis de Ambiente

Gerencie ENV vars de forma segura pela interface. Elas são injetadas no container automaticamente.

Como funciona

Da ideia ao ar em 4 passos

1
Crie um App

Dê um nome para o seu projeto na plataforma. Simples assim.

2
Cole o repositório

Informe a URL do seu repositório no GitHub e dispare o deploy.

3
Acompanhe os logs

Veja em tempo real o processo de build e deploy diretamente no painel.

4
Acesse sua URL

Sua aplicação estará rodando com URL própria e autoscaling ativo.
